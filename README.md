# Student Management System

A Student Management System built using Python and SQL that performs CRUD operations to manage student records.

## Features

- Add new students
- View student records
- Update student details
- Delete student records
- Export data to CSV

## Technologies Used

- Python
- SQLite
- Tkinter
- SQL

## How to Run

1. Clone the repository
2. Run database.py
3. Run main.py
